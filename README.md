# Dawood Syed

Senior Data Engineer based in High Point, North Carolina. I build streaming data pipelines that land change data capture feeds into Apache Hudi tables and serve them through Trino. Day to day that means Apache Spark Structured Streaming, Kafka, Debezium, Airflow, and Terraform on AWS, with Java and Spring Boot services around the edges.

## What I am working on

StreamVault Lakehouse is my current side project. It takes Debezium change events off Kafka, applies them into Hudi tables with Spark, and exposes the result to Trino for ad hoc queries. The sample data is a small orders and inventory set so the whole stack runs locally with docker compose. Details live in the repo at https://github.com/syeddawood9082-dev/streamvault-lakehouse
